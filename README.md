# Классификация распространённых российских дорожных знаков по изображению

**Командный проект в рамках магистерской программы по специальности "Искуственный интеллект", Факультет Компьютерных Наук, Высшая Школа Экономики (ВШЭ).**

---

## Описание проекта

**Тема:** Классификация распространённых российских дорожных знаков по изображению

**Цель:** создать сервис, которые по фотографии знака определяют его класс по ПДД РФ и показывают название, группу и справочное изображение.
