# Классификация российских дорожных знаков

**НИУ ВШЭ · Факультет компьютерных наук**  
**Магистерская программа «Искусственный интеллект» · 2026–2028**  
**Годовой проект · 2026–2027**

## О проекте

**Тема:** Классификация распространённых российских дорожных знаков по изображению.

**Цель:** Разработать и сравнить модели классификации российских дорожных знаков и реализовать сервис, который по фотографии знака определяет его класс по ПДД РФ и отображает название, группу и справочное изображение.
